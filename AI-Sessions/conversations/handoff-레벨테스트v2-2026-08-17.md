# 인수인계 — 레벨테스트 v2 (원격 → 로컬)

## Summary

레벨테스트 개편(v2) 설계와 고등 판정 시트 구현까지 끝냈다. **다음 한 걸음이 공유폴더 확인인데, 원격 세션에서는 물리적으로 불가능해서 로컬 세션으로 넘긴다.**

로컬 세션이 할 일은 하나다 — 레벨테스트 채점 엑셀에 **어휘 4구간 소계(또는 문항별 정오)** 가 남아 있는지 확인. 있으면 파일럿 하나를 역시행 없이 끝낼 수 있다.

## Context

### 왜 넘기나

원격 세션은 클라우드 컨테이너에서 돌아 학원 내부망에 못 붙는다. 확인 완료:

- `mount`에 cifs/smb/nfs 항목 없음. `\\desktop-07gd04s`는 내부망 이름이라 외부에서 해석 자체가 안 됨
- 구글 드라이브에는 `중듵레벨테스트듣기.mp3`(중등 듣기 음원)뿐 — 채점 엑셀 없음
- vault 안에 엑셀·CSV 0개

```
cd <vault>
```

### 2. 로컬에서 할 일 — 공유폴더 확인

위치: `\\desktop-07gd04s\일곡점 공유폴더2\레벨테스트\` (중등 = 하위폴더 `...중등레벨테스트지_그래머에이스...`)

순서대로 셋:

1. **파일이 학생 이름·날짜별로 쌓여 있나, 템플릿 한 벌인가?**
   템플릿 한 벌 = 응시할 때마다 덮어썼다는 뜻 → 과거 데이터는 마지막 한 명분뿐 → 아래 3번은 볼 것도 없이 역시행 파일럿으로 간다.
2. 쌓여 있다면, **결과분석(또는 관리자용) 시트에 문항 번호 열·O/X 열이 있나, 영역별 합계뿐인가?**
3. ★ **어휘 6~35번이 초급/중급/준고급/고급 소계로 나뉘어 있나?**

**3번이 진짜 조건이다.** 문항별 O/X까지 필요 없다. 판정 시트가 받는 입력이 구간별 정답 수 4개뿐이라, 4개 소계만 있으면 v2 재계산이 100% 된다. 원본 평가지가 어휘를 구간별로 배열해 놨으니(6~10 초급 · 11~15 중급 · 16~30 준고급 · 31~35 고급) 채점표에 소계가 있을 가능성이 있다.

### 3. 확인 결과에 따른 분기

**데이터가 있으면** — 과거 응시자를 전부 판정 시트 로직으로 재계산하고, 현행 총점 판정과 **결과가 갈리는 학생 수를 센다.**
- 갈리는 학생이 유의미하게 나오면 → 어휘 도달구간 판정은 값어치가 증명된 것. §9 파일럿 #2를 역시행 없이 종료.
- 0명이면 → v2 어휘 변경은 무가치. **롤백한다.** (설계안 §9에 이미 롤백 조건으로 박아둠)
- 덤으로, 그 학생들이 실제로 어떤 교재를 받았고 이후 성적이 어땠는지까지 붙이면 컷 보정의 첫 실데이터가 된다.

**데이터가 없으면** — §9 파일럿 #1대로 재원생 15~20명 역시행. 고등은 문항이 현행 그대로라 기존 평가지로 지금 바로 가능하다.

## 주의

- v2는 **draft다.** 파일럿 실측 전까지 신규생을 v2로 배치하지 않는다. 현행 [[레벨테스트]] 기준으로 받는다.
- 엑셀에 학생 이름이 들어 있어도 **위키에는 구조·집계만** 쓴다. PII는 쓰지 않는다.
- 공유폴더 원본은 **읽기만** 한다. 재계산은 사본으로.
