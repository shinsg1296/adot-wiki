## A. 로컬에서 바로 할 일 — 첫단추 1회차 등록

### 목표
첫단추 독해실전편 **실전 1회(25지문)** 를 러닝 스튜디오 `/content/new`에 등록. 베타 확인이 목적이므로 전권(300지문)이 아니라 **1회차만** 먼저.

### 1단계 — 데이터 뽑기

소스: **`C:\시험지분석\master\passage_bank.json`** (4,594지문)

필터 조건 (위키 [[원문마스터뱅크_재편_2026-07]] 기준):
- `category` = `extra`
- `book` = `첫단추 독해실전편`
- `lesson` = 회차 (실전 1회)
- source 라벨 형식 = `첫단추 독해실전편 <회차> N번`

⚠️ **필드명은 추정이다. 먼저 실제 구조를 확인하고 맞출 것.**

```python
import json, collections
BANK = r"C:\시험지분석\master\passage_bank.json"
d = json.load(open(BANK, encoding="utf-8"))
items = d if isinstance(d, list) else next(v for v in d.values() if isinstance(v, list))
print("총:", len(items))
print("키:", list(items[0].keys()))
print(collections.Counter(
    i.get("book") for i in items if "첫단추" in str(i.get("book", ""))))
# 첫단추 항목 하나를 통째로 찍어 라벨 형식 확인
print(json.dumps(next(i for i in items if "첫단추 독해실전편" in str(i.get("book",""))),
                 ensure_ascii=False, indent=1)[:800])
```

### 2단계 — ⚠️ 한글 해석이 없다

위키에 명시돼 있다:

> `_dansu_parse.py`(본문해석지 docx 표 파싱: **좌열=영어 본문만**)

즉 `passage_bank.json`에는 **영어만** 있고 우리말 해석은 버려졌다.

러닝 스튜디오는 영어만으로도 등록되지만, **직독직해 · 입영작 · 한글 보고 영어로 말하기** 훈련은 우리말이 있어야 동작한다(화면 문구: *"우리말이 등록되지 않은 문장이에요"*).

**선택지**
- **① 영어만 먼저** — 뱅크에서 바로 뽑아 등록. 베타 확인용으로 충분. **권장**
- **② 해석까지** — worksheetmaker 본문해석지 **docx 원본**을 다시 파싱(표 우열 = 한글). `_dansu_parse.py`를 좌우열 모두 뽑도록 고쳐 쓰면 된다

①로 시작하고 잘 돌면 ②로 재등록하는 순서를 권한다.

### 3단계 — 문장 분리

지문 단위 → **문장 단위**로 쪼개야 한다. 러닝 스튜디오는 문장이 등록 단위다.

주의: `Mr.` `Dr.` `etc.` `U.S.` 같은 약어와 인용부호에서 잘못 끊긴다. 단순 `.` 분리 금지. 분리 후 눈으로 검수할 것.

### 4단계 — 등록 화면 사용법 (2026-08-31 실물 확인)

**CSV 업로드는 없다.** 탭 구분 텍스트를 붙여넣는 방식이다.

textarea 안내문 그대로:
> 엑셀에서 영어·우리말 두 칸을 복사해 그대로 붙여넣으세요.
> 엑셀 두 칸 복사 · 영어 / 우리말 · **영어만 — 세 가지 다 됩니다.**
> 줄 앞 번호(1. 2. 3.)는 알아서 떼어 냅니다.

형식:
```
영어 문장<TAB>우리말 뜻
영어 문장<TAB>우리말 뜻
```

**★ 이 화면은 "본문 1개" 단위다.** `단원 번호` + `본문 번호`가 한 세트이므로 **지문마다 한 번씩, 25번 반복**해야 한다. 한 번에 다 넣는 화면이 아니다.

### 5단계 — 교재 설정값

| 칸 | 값 |
|---|---|
| 이미 있는 교재에서 고르기 | **새 교재로 넣기** (첫 지문만. 이후엔 목록에서 선택) |
| 출판사 | 쎄듀 |
| 교재 이름 | 첫단추 독해실전편 |
| 어떤 자료인가요? | **부교재** (교과서/부교재/Syntax/자체자료 중) |
| 학교급 · 학년 | 고등 · 1학년 (경신여고1 부교재) |
| 단원 번호 — 정렬용 | 1 (= 실전 1회) |
| 본문 번호 | 01, 02, 03 … 25 |
| 단원 이름 | 실전 1회 |

두 번째 지문부터는 맨 위 드롭다운에서 교재를 고르면 출판사·교재명·학년이 붙는다. **본문 번호만 바꾸면 된다.**

### 6단계 — 입력

지문 25개를 사람이 손으로 넣는 건 비효율적이다. 두 방법:

- **Claude in Chrome** — 원장님이 이전에 학생 명단을 이 방식으로 입력한 전례가 있다. 로컬 세션이 만든 붙여넣기 블록을 넘겨 자동 입력
- 로컬 세션이 블록만 만들고 원장님이 복사·붙여넣기

로컬 세션은 **지문별 블록 25개**를 아래 형태로 산출하면 된다:

```
[본문 01]  단원 1 · 본문 01
<영어문장><TAB><우리말>
<영어문장><TAB><우리말>

[본문 02]  단원 1 · 본문 02
...
```

### 시작 전 확인 한 가지
화면의 **"예시 넣어보기"** 버튼을 먼저 눌러 실제로 어떤 형식이 채워지는지 확인할 것. 위 형식과 다르면 거기 맞춘다.
