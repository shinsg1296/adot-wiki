# SOP 학부모 안내 문자 (시험 결과·퇴원·인수인계)

## Summary

원장이 상황을 말해 주면 AI가 문자를 정돈한다. **관제에서 일정·숙제를 확인해 사실을 채우고**, 아래 원칙으로 쓴다.
톤은 [[톤앤매너]]를 따르되 학부모 대상이라 평소 말투보다 차분하게, 이모지는 쓰지 않는다.

## 1. 공통 원칙 (원장 교정에서 나온 것)

| 원칙 | 이유 |
|---|---|
| **아이 탓으로 읽히지 않게 쓴다** | "의욕이 없다"를 그대로 쓰면 성격 지적이 된다 → "어려움이 쌓여 마음이 꺾이는 흐름"으로 |
| **사과는 한 번만** | 반복하면 어머님이 위로를 해야 하는 부담이 생긴다 |
| **부족한 점 뒤에는 반드시 해법** | 진단만 있으면 탓, 해법이 붙으면 조언 |
| **먼저 꺼내지 않은 이야기는 넣지 않는다** | 학부모가 퇴원을 말하지 않았는데 마무리 인사를 넣으면 **먼저 끊으라는 신호**가 된다(원장 교정 9/29) |
| **앞으로의 계획은 상황을 보고** | 오래 맡겼는데 성적이 안 나온 경우 "이렇게 하겠습니다"가 설득처럼 들린다(원장 교정 9/29) |
| **일정·숙제는 관제 값을 그대로** | 명단이 옛 값일 수 있으니 **프로필 우선**(effDay/effTime). 자습 요일까지 확인 |
| 마지막은 **여지를 남긴다** | "하실 말씀 있으시면 편하게" — 학부모가 하고 싶은 말을 꺼낼 자리 |

## 2. 상황별 뼈대

### (1) 퇴원이 확정된 경우 — 감사 + 마지막 피드백
인사 → 감사 → 이번 시험 결과와 틀린 이유(구체적으로) → 앞으로 어디서 공부하든 필요한 것 → 응원.
※ 환불·마지막 수업일은 넣지 않는다(필요하면 원장이 추가).

### (2) 성적이 계속 안 나와 아쉬운 경우 — 퇴원 언급 없이
인사 → **죄송·아쉬움 한 번** → 제가 본 아이 이야기(막힌 고리 설명) → "노력하지 않은 게 아니라 이 고리를 끊어주지 못한 게 아쉽다" → 응원 + 여지.
※ 학부모가 먼저 마무리를 꺼내지 않았으면 마무리 인사·계획 제안을 넣지 않는다.

### (3) 시험 끝난 뒤 안내 — 결과 + 다짐 + 일정
인사 → **[이번 시험]** 점수와 잘한 부분·깎인 부분(몇 점짜리인지) → **[아이와 나눈 이야기]** 본인 말 인용 + 약속한 교재 →
**[수업 인수인계]**(담당이 바뀌는 경우) → **[앞으로 일정]** 등원·수업·자습 → **[이번 주 숙제]** 기한과 항목 → 마무리.

## 3. 실제 문구에서 통했던 표현

- "암기와 독해는 준비한 만큼 그대로 나왔습니다. 다만 암기로 해결되지 않는 문법·서술형에서 31점이 깎였습니다. **이 부분만 잡았다면 91점대**였습니다." → 점수를 **가능성**으로 환산해 보여준다
- "개념을 하나씩 짚어 줄 때는 잘 따라옵니다. 그런데 한 문장에 개념이 두세 개 겹치면 **무엇을 써야 하는지에서 흔들립니다**." → 못한다가 아니라 **어디서 막히는지**
- "시후가 새로 적응할 것 없이 **하던 흐름 그대로** 이어가겠습니다." → 담당 교체 불안을 먼저 덮는다
- 담당 교체는 **사유를 쓰지 않는다**. "시험이 끝나는 시점에 맞춰 제가 직접 이어받았습니다"까지만

## 4. 쓰기 전 관제에서 확인할 것

- 수업 요일·시간(**프로필이 명단보다 우선**), 자습 요일·시간, 그 주 이동/보충
- 이번 주 숙제와 기한(`/api/hw/week`), 필요하면 단어 자동배정으로 다음 주 숙제까지
- 시험일·시험범위(내신 보드)
