# SOP — 파이널고사 제작 → 인쇄 → 빠른채점

## Summary

학교 한 곳의 파이널고사를 **직전 시험 틀 그대로** 만들고, 검증하고, 학원 프린터로 뽑고, 빠른채점에 여는 표준 절차. 2026 2학기 중간 시즌([[2026_2학기중간_파이널_시즌]])에서 25개 넘는 시험지로 검증했다. 계열 설명은 [[하위파이널_내신제작]], 실패 사례는 [[파이널_제작운영_실패패턴_2026-09]]·[[파이널_문항생성_실패패턴]].

## Context

- 작업 폴더: `C:\내신변형\<반>중간2\` (`_src` 원본·쪽 이미지, `_bp` 읽기 결과, `_blueprint_*.md` 설계도, `_plan.json/.md` 슬롯표, `_gen\G*.json` 묶음 문항, `_q.json`·`_key.json` 조립본, docx·pdf 산출물).
- 큰 작업은 **시작 전에 규모(작업자 수)를 원장에게 알린다**(원장 2026-09-22). 실측: 학교 1곳 = 작업자 12~30개·200만~470만 토큰.
- 배포·라이브 반영(보드 등록·빠른채점·시트 쓰기)은 **원장 허락 뒤**. 생성·초안·렌더는 자유.

## Details

### 1. 설계도 — 어느 시험을 틀로 쓰나 (원장 확정)

| 경우 | 틀로 쓰는 시험 |
|---|---|
| 기본 | 직전 정기시험 |
| 중1 2학기 중간 | 작년 같은 학교 중1 2학기 중간(1학기가 자유학기) |
| 중2·3 2학기 중간 | 작년 2학기 중간이 있으면 그 시험, 없으면 올해 1학기 기말 |
| 원장이 시험지를 지정 | 그 시험 (예: 양산중3 = 2024 2학기 중간) |

- 틀 = 문항 수·배점(소수점까지)·유형 구성·서술형 위치와 형식·발문 문체. 내용은 올해 범위 지문으로 새로 낸다.
- **중학 시험은 작년 시험과의 유사성보다 '해당 과 내용에 맞는 문제'가 우선**, 유형만 비슷하게(원장 2026-09-28).
- 원본이 학생 응시본이면 손글씨는 읽지 않고, 공식 정답표가 없으면 직접 풀어 확정한다.
- 스캔본은 쪽 순서가 뒤바뀔 수 있다 → 쪽 아래 인쇄된 쪽 번호로 먼저 확인.

### 2. 범위와 재료

- **범위는 원장 확인이 먼저다.** 추정으로 만들면 학생이 "처음 보는 지문"을 만난다(→ 실패패턴 7번).
- 지문은 원문뱅크(`C:\시험지분석\master\passage_bank.json`)에서 꺼내 작업 폴더 `_bank.json`으로 모은다. 없는 교과서 과는 공유 자료의 본문 파일에서 추출하고 직독직해·프리내신과 문장 단위로 대조한다.
- 모의고사 지문은 **재료 점검**을 거친다: 어법·어휘 지문에 오답 낱말이 남았는지, 무관 문장이 끼어 있는지, 순서·삽입 지문이 원문 순서인지, 빈칸이 채워져 있는지. 점검 결과는 `clean_text` 칸에 넣고 이후 단계는 그것만 쓴다.

### 3. 제작 흐름 (작업자 단계)

1. **읽기** — 직전 시험지를 2쪽씩 나눠 구조·출제 포인트 분석(`_bp\R*.json`).
2. **설계** — 설계도 + 슬롯표(`_plan.json`: order·expect·groups). 정답 번호는 미리 배정(①~⑤ 고르게, 3연속 금지).
3. **설계 검증** — 다른 작업자가 슬롯표를 원본·재료와 대조해 직접 고친다.
4. **생성** — 3~4묶음으로 나눠 문항 작성(`_gen\G*.json`).
5. **블라인드 풀이** — 정답 없는 파일(`_blind\G*.json`, 도구 `_jung_blind.py`)만 읽고 푼다.
6. **검수·교정** — 풀이 대조·지문 글자 대조·누수·형식·해설 동기화. 파일을 직접 고친다.
7. **재풀이** — 고친 문항만 다시 블라인드. 어긋나면 2차 교정.
8. **전체 감사** — 구성·누수 관점 1명, 영어·난이도·서술형 관점 1명. 그 뒤 마무리 교정.
9. **조립** — `py -3 C:\내신변형\_jung_assemble.py <폴더>` → `검사: 이상 없음`.
10. **완성본 독립 풀이** — 외부 전달용은 전체를 2회 더 푼다(장성고1: 25/25 두 번).

중단된 제작은 `_gen` 파일이 남아 있으면 **재생성 없이 조립만**으로 끝낼 수 있다(토큰 절약).

### 4. 문항 파일 규칙 (조립이 읽는 형식)

- 배점은 발문 끝 대괄호 `[3점]`, 서술형 `(각 3점) [6점]`. `(3점)`·`[6점, 각 3점]`은 조립 실패.
- 밑줄 = 지문 `①{word}`·`(A){어구}`, 선지·상자 `__word__`. 빈칸 = 밑줄 문자 8개 이상.
- 세트 지문은 머리글에 한 번만. 서술형 key 이름은 `서N`, 단답형은 `단N`.
- 순서·삽입은 원문 문장을 그대로 잘라 만들고 '합본 == 원문'을 코드로 검증.
- 답지 key에는 문항별 출처(source)를 빠짐없이 적는다.

### 5. 렌더와 서식

- 한 번에: `py -3 C:\내신변형\_jung_render_all.py <폴더>` (시험지 + 답지 + 결함 검사 + 쪽 배치 그림). **순차 실행만**(Word 동시 실행 금지).
- 용지: **고등 시험지 B4 · 중등 시험지 A4 · 답지 전부 A4**(원장 2026-09-27~28).
- 서식 원칙: 문항은 쪼개지 않는다, 세트 지문은 같은 쪽 안에서 단을 넘어도 된다, 쪽 넘김은 금지.
- 자동 배치가 어색하면 수동 도구로 고친다.
  - 나눔 옮기기: `_docx_break_edit.py <docx> list | remove "19." | add-col "20." | add-page "22."`
  - 문항 앞 간격 넓히기(끝단 맞춤): `_docx_gap_edit.py <docx> "19." 170`
- 렌더 뒤 `_scan_final_defects.py` 결함 0 확인.
- **인쇄 전에 배치를 원장에게 보여 준다**(원장 2026-09-28).

### 6. 인쇄

- 도구: `C:\내신변형\_print_finals.py` (JOBS 표에 이름·docx·용지·부수 → 인자 없이 미리보기, `go`로 인쇄).
- 규칙(원장 확정): **흑백 복합기 iR-ADV 6255 · 양면 · 부수 = 재원생 + 1**.

### 7. 보드 등록 (원장 허락 뒤)

- `C:\내신변형\_print_materials\register_finals.py`의 ENTRIES에 추가 후 실행 → 내신 보드 '파이널고사 출력' 버튼에 뜬다.

### 8. 빠른채점 (원장 허락 뒤)

- `_register_final_grade.py`의 FINALS 표에 추가 → 미리보기 → `go <학교>`. 정답키 시트까지 동기화된다.
- 새 시험이면 학생 앱 목록(EXAM_META) 한 줄을 정본에 패치해 배포해야 뜬다. 상세는 [[빠른채점]].
- 채점하면 틀린 문항의 정답이 보인다 → 기본은 그 반이 시험 볼 때만 연다.
- 등록 뒤 답지와 정답을 대조한다.

### 9. 외부 서식으로 넘기기 (선택)

- 다른 도구(GPT Codex 등)가 학교 서식 PDF를 만들 때는 문항을 그 도구의 입력 규격으로 변환해 파일 경로만 넘긴다. 정답·해설은 넣지 않는다.
- 사례: 장성고1 → `_export_codex_json.py`(우리 표식을 `<u>` 태그로 변환, 쪽·단 어림 배치).

### 10. 할 수 없는 것

- **기출 시험지를 글자 그대로 통째 전사해 다시 찍는 일은 하지 않는다.** 대안은 '기출 밀착 변형'(번호·유형·배점·정답 번호·출제 포인트 1:1, 교과서 밖 문장만 새로) 또는 원문을 사람이 직접 입력.
