# 레벨테스트 v2 설계안 (신규생 진단·배치)

## Summary

현행 [[레벨테스트]](고등 수능용 · 중등 그래머에이스)를 **지필 한 장에서 진단 패키지로** 개편하는 설계안. A접수 → B평가 → C보조진단 → D판정 4층.

핵심 변경 3개:

1. **어휘를 총점이 아니라 '도달 구간'으로 판정** — 코스 길이는 "얼마나 아느냐"가 아니라 "어디까지 아느냐"가 결정한다.
2. **암기 레버를 측정 항목에 편입** — [[내신_성적향상_로드맵_방법]]의 진단 두 레버 중 현재는 기본기 하나만 측정하고 있다.
3. **학교 성적·출제 프로파일을 전략 레이어로 결합** — 단, **배치 결정권은 레테가 유지**한다.

> **status = draft.** 배점·컷은 전부 **제안**이며, §9 파일럿으로 실측하기 전에는 현행 운영 기준을 바꾸지 않는다. 확정 시 [[레벨테스트]]를 갱신하고 이 문서는 `superseded`로 내린다.

### 개편 범위의 한계선

**문항은 새로 만들지 않는 것을 1순위로 한다.** 기존 평가지 문항은 수년간 실사용으로 난이도가 암묵 검증된 자산이고, 새로 쓰면 그 검증이 사라진다. v2는 **구성표·판정 로직·결과지**를 바꾸고, 문항은 기존 풀에서 재배치한다. 새 문항은 부족분(중등 문법 증량분·영작)만 제작한다. ([[기획기준]] 최소 영향)

## Details

### 0. 설계 원칙

1. **배치 결정권은 레벨테스트에.** 절대 실력을 영역별 해상도로 재는 유일한 수단이다.
2. **학교 성적은 전략 레이어.** 목표 등급·시험 성격·내신 전환 시점을 정하되, 교재를 정하지 않는다. (학교 간 비교 불가 + 영역 해상도 없음)
3. **측정하지 않는 것으로 배치하지 않는다.** 교재 결정 축마다 대응 측정 영역이 1:1로 있어야 한다.
4. **1회 측정은 사전 추정.** 첫 내신 결과가 갱신한다 → [[내신_성적향상_로드맵_방법]] 4.보정 루프.

### 1. 4층 구조

| 층 | 무엇 | 담당 | 시점 |
|---|---|---|---|
| **A. 접수** | 학년·학교·유입경로 + **직전 2회 성적·모의 등급·목표** | [[3_상담소통부]] (원장 전화) | 레테 날짜 잡을 때 |
| **B. 평가** | 지필 + 듣기 (100점) | 조교 감독 | 응시 60분 |
| **C. 보조진단** | 음독 30초 + 문진 5문항 | 조교 | 응시 직후 5분 |
| **D. 판정·배치** | 축별 배치 + 학교 레이어 + 갭 플래그 + 결과지 | [[2_교무부]]·원장 | 당일 상담 |

현행 대비 신설은 A의 성적 항목 · C 전체 · D의 학교 레이어. B는 구성 개편.

### 2. A. 접수 (전화 단계 추가 항목)

현행 흐름(학년·학교·유입경로 → 레테 날짜 → 이름)은 그대로 두고 뒤에 붙인다.

- 직전 **2회** 영어 내신: 원점수 · 석차등급 · 과목평균 · 수강자수 (성적표 사진이 정확)
- 최근 모의 등급 (있으면)
- 목표 등급·기한

**받는 방식**: 성적표 사진 → [[성적관리카드_시스템]] 저장. 구두 성적은 부풀려지므로 원본 기준.

**없으면 그냥 진행한다.** 중3→고1 전환·자유학기제 등으로 성적이 아예 없는 신규생이 상당수이고, 있어도 3~6개월 전 것이다. 이 층은 **보강재이지 전제조건이 아니다.**

> 문구 주의: "성적표 주시면 성적이 오릅니다" 류의 보장 표현 금지 → [[금지표현]]. "학교 시험 유형까지 반영해 배치해 드립니다" 정도.

### 3. B. 고등 트랙 (수능용) — 구성 개편

| 영역 | 현행 | v2 (제안) | 왜 |
|---|---|---|---|
| 듣기 | 5문항 / 10점 | **유지** | 고듣끝 실전/유형 2분기만 필요 — 해상도 충분 |
| 어휘 | 30문항 / 30점 | 30문항 / 30점 — **구간별 산출 추가** | §5 판정 참조 |
| 구조 | 15문항 / 30점 | 12문항 / 24점 + **영작 2문항 / 6점** | 내신 서술형 대비 능력은 인지(객관식)와 산출(영작)이 다르다 → [[서술형_출제원리_v2]] |
| 독해 | 15문항 / 25점 | 유지 + **소요시간 기록** | 상위권은 실력이 아니라 시간이 병목인 구간이 있다 (예: [[김지우]] "70점대 안정 → 시간관리 단계") |
| 언어력 | 5문항 / 5점 | **유지** | 하(0~3) = 국어 언어력부터 — 게이트 역할 |

총점 100 유지. 어휘 구간(현행): 초급 6~10 · 중급 11~15 · 준고급 16~30 · 고급 31~35.

### 4. B. 중등 트랙 (그래머에이스) — 배점 재조정

| 영역 | 현행 | v2 (제안) |
|---|---|---|
| 듣기 | 5 | 5 |
| 어휘 | 30 | 25 |
| **문법** | **14** | **30** |
| 구조 | 20 | 15 |
| 독해 | 23 | 20 |
| 언어력 | 8 | 5 |

근거: 중등 내신 = **교과서 83%** 문법 중심([[내신_분석_시스템]] 실측)이고, 배치하는 교재 자체가 문법 교재다. 결정 축의 배점이 14점이면 판정이 흔들린다.

### 5. D. 판정 로직 (축별 독립 배치)

교재는 축별로 독립 결정한다. 총점은 상담용 요약일 뿐 배치 근거가 아니다.

#### 고등

| 축 | 입력 | 배치 |
|---|---|---|
| 듣기 | 듣기 10점 | 상·중 = 고듣끝 실전편 / 하(0~4) = 유형편 *(현행 유지)* |
| **어휘** | **도달 구간** | 아래 표 |
| 독해 | 구조+독해+언어 60점 | Intermediate 51~60 · Basic 26~50 · Build-Up 11~25 · Start-Up 0~10 *(현행 유지)* |
| 언어력 | 5점 | 하(0~3) = 국어 언어력 병행 권고 *(현행 유지)* |

**어휘 도달 구간 판정** (신설): 각 구간 정답률 **70% 이상 = 통과**. 아래에서부터 연속 통과한 마지막 구간이 도달 구간.

| 도달 구간 | 배치 | 현행 총점 매핑 대비 |
|---|---|---|
| 고급 | 어휘끝 어원편 | ≈ 상(26~30) |
| 준고급 | 고단끝 2개월 | ≈ 상~중상 |
| 중급 | 고단끝 3개월 | ≈ 중상(21~25) |
| 초급 | 고단끝 6개월 | ≈ 중(11~20) |
| 초급 미통과 (40~69%) | 중학 30일 | ≈ 중하(6~10) |
| 초급 미통과 (40% 미만) | 중학 60일 | ≈ 하(0~5) |

총점 판정과 갈리는 지점이 이 변경의 전부다. 예를 들어 **총점 20점**인 두 학생:

- 초급 5/5 · 중급 5/5 · 준고급 10/15 · 고급 0/5 → 현행 "중 = 6개월" / v2 **3개월** (준고급 진행 중)
- 초급 2/5 · 중급 2/5 · 준고급 12/15(찍기 포함) · 고급 4/5 → 현행 "중 = 6개월" / v2 **중학 60일** (기초 구멍)

두 학생에게 같은 코스를 주는 것이 현행의 실제 손실이다. 이 손실이 실제로 얼마나 자주 생기는지는 §9에서 센다.

#### 중등

| 축 | 입력 | 배치 |
|---|---|---|
| **문법 트랙** | **문법 + 구조 = 45점** | Grammar Ace 1 (0~17) · Grammar Ace 2 (18~35) · Build-up (36~45) |
| 어휘 | 어휘 25점 | 중단끝 코스 길이 (고등과 같은 구간 방식) — 학교 단어장 사용자는 학교 것 우선 ([[교무부_운영룰]] #6) |
| 듣기·독해·언어 | 각 영역 | 참고 지표 (상담·특이사항용) |

컷은 **현행 비율을 그대로 승계**했다(현행 총점 0~40% / 41~80% / 81~100% → 45점 기준 0~17 / 18~35 / 36~45). 컷을 새로 발명한 게 아니라 **축만 바꾼 것**이다.

### 6. D. 학교 레이어 (성적·프로파일 결합)

배치가 끝난 뒤에 얹는다. 순서를 바꾸면 원칙 2가 깨진다.

1. **학교 프로파일 조회** — `C:\시험지분석\report\학교별\<학교>.md` (36개 구축). 없으면 3개년 기출 분석을 백로그로 걸고 이 단계는 건너뛴다.
2. **시험 성격 확정** — 암기형(암기 커버 高) / 기본기형(외부지문 高) → [[내신_성적향상_로드맵_방법]] 전략 매트릭스로 목표 등급별 경로 결정.
3. **내신 전환 시점 가감** — 기본 5주 전([[교무부_운영룰]] #1)에서 조정. 암기형 + 목표 2등급이면 앞당길 여지, 기본기형이면 전환보다 정규 기본기 유지가 낫다.
4. **갭 플래그** — 아래.

#### 갭 플래그 (레테 밴드 × 내신 밴드)

레테 밴드(상/중/하)와 내신 등급 밴드(1~2 / 3~4 / 5~9)가 **2밴드 이상** 벌어지면 원장 리뷰 대상으로 표시한다.

| | 내신 높음 | 내신 낮음 |
|---|---|---|
| **레테 높음** | 정상 궤도 → 변별·심화 대비 | ⚑ 암기 투자·학교 대비 부족. **교재 낮추지 않는다** — 처방은 내신 전환 시점·암기 루틴 |
| **레테 낮음** | ⚑ 암기형 학교 + 성실. 배치는 레테대로, **천장 경고**를 상담에서 미리 말한다 | 기본기부터, 목표 현실화 |

플래그는 **배치를 바꾸지 않는다.** 상담 메시지와 첫 8주 플랜을 바꾼다.

### 7. C. 보조 진단 (5분, 조교)

#### 음독 30초

지문 3문장을 소리 내어 읽게 하고 체크: ① 모르는 단어에서 멈춤 ② 자모음 오류 ③ 속도.

**'발음 불가' 판정이면 암기법 매칭보다 발음이 먼저다.** 발음을 못하는 채로 외우는 학생은 암기 준비가 안 된 것 — 이미 [[교무부_운영룰]] §암기법 매칭에 있는 규칙인데, 지금은 배치 시점에 알 방법이 없어 몇 주 뒤 단어 재시험이 반복되고서야 드러난다.

#### 문진 5문항 (채점 없음)

암기 투자 가능량 = 진단 두 번째 레버의 입력.

1. 주당 영어에 쓸 수 있는 시간
2. 단어 암기 경험·방법 (깜지 / 발음 / 연상 / 없음)
3. 최근 3개월 학원·인강 이력
4. 시험 2주 전 공부량 (자기보고)
5. 목표 등급·점수

시험이 아니라 문진표다. 점수화하지 않고 [[템플릿_성적향상로드맵]] "암기 투자 가능량" 칸에 그대로 들어간다.

### 8. 결과지 · 운영 동선

#### 결과지 5블록

1. 영역별 점수 + **어휘 도달 구간**
2. 배치 결과 (교재·코스·주간 분량)
3. 학교 시험 성격 (프로파일 있을 때만)
4. 첫 8주 계획
5. 재측정 시점 (= 첫 내신)

문구 규칙: 성적 보장·학생 비하·타 학생 비교 금지([[금지표현]]), 능동 시점([[톤앤매너]]), 이모지 금지. 등급별 총평 문구는 현행 엑셀(결과분석/총평 시트)을 재사용한다.

### 10. 자동화 훅 (R1: 판정 설계=교무부 / 엔진=[[5_시스템개발부]])

- **응시는 종이 유지.** 신규생 첫 접점에서 폰 제출은 리스크가 크다.
- **채점**: [[빠른채점]]에 '레벨테스트' 카테고리 추가 (객관식). 영작 2문항만 수동.
- **판정**: 매핑표가 전부 결정론적이므로 점수 → 배치는 스크립트로 계산 가능.
- **저장**: [[성적관리카드_시스템]] JSON에 `레벨테스트` 블록 추가 → 관제 대시보드 학생 프로필에 노출.
- **누적 자산**: "레테 ○○점 학생이 △△고에서 실제로 몇 등급 나왔나"가 쌓이면 학교별 컷 보정이 가능해진다. 학원 밖에서는 만들 수 없는 데이터다 ([[내신_성적향상_로드맵_방법]] §자체 오답률 proxy와 같은 논리).
