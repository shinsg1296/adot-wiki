기존 [[레벨테스트]](본사 기준표, 2026-06-07 문서화)를 대체하는 **자체 진단 설계**. 기준표는 그대로 두고 이 문서가 제작 정본.
담당: [[5_시스템개발부]] 구현 / [[2_교무부]] 교육 판단 · 상태: **착수**

| 구조력 30점이 한 덩어리 | 관계사에서 막힌 애와 수일치에서 막힌 애가 같은 점수 → [[오답진단_질문체인]] 연결 불가 |

| 1회성 엑셀 | 재측정·성장 증명 불가 |

## 원장 결정 (2026-09-05)

- 대상 = **고등·중등 동시** (공통 엔진, 파라미터 교체)
- 매체 = **하이브리드** (어휘 사다리·암기 흡수율 = 태블릿 / 구조·독해·언어력 = 종이)
- 시간 = **50분**
- 목적 = 배치 정확도 + 상담 전환율 + 성장 추적 **셋 다**

## 측정 모델 — 실력을 7축으로

1. **어휘 폭** — 적응형 급수 사다리 A1~A9 (아래 실측 결과)
2. **인출력** — 재인(영→한) vs 산출(한→영 철자) 갭 + 발음 5단어 구두 체크(교무부 룰의 "발음 못하면 암기 준비 안 됨" 게이트)
3. **문장 해독 12노드** — 주어·동사 / 수일치(분리 후) / 시제 / 태 / 관계사 / 분사 / to부정사 / 동명사 / 병렬 / 지시어 / 도치 / 가정법. 가중치는 [[어법 출제 원칙]] 따름
4. **독해 처리량** — 난이도 계단(중3→고1→고2→고3) + 지문별 시간 = WPM × 유형별 정답률
5. **듣기** — 유형 구분(목적/정보·숫자/추론)
6. ★**암기 흡수율** — 1차에서 **틀린 단어 중 10개**를 5분 암기 → 방해 과제(독해) → 지연 회상(뜻+철자). *유일하게 "현재 실력"이 아니라 "성장 속도"를 재는 파트* (원장 발명)
7. **언어력** — **한국어 지문** 요약 1문항. 영어 문제인지 문해력 문제인지 분리

## ★ ROI 프레임 — 진단의 결론은 "약점"이 아니라 "점수 상승 우선순위"

원장 지적: 고2 2학기 학생에게 문법 2문항 때문에 3주를 태우는 건 전략이 아니다.

| 구분 | 예시 |
|---|---|
| 즉시 점수화 | 본문 암기, 서술형 조건, 변형문제, 시험범위 어휘 |
| 최소 방어 | 시험범위 문법 포인트만 (= **문법 치료가 아니라 문법 방어**) |
| 장기 보완 | 절·준동사·관계사 기초 |
| 이번 시험 비추천 | 문법 개념서 처음부터 완강 |

→ 학교별 배점 구조를 [[시험지 분석 엔진]] 자산에서 자동 로드해 계산. **범용 제품이 구조상 못 하는 부분.**

## 어휘 사다리 A1~A9 (2026-09-05 실측)

원장 교정 반영: **표제어를 학원 교재에서 뽑지 않고 시험 지문 코퍼스에서 직접 추출**(9,317개).
코퍼스 = passage_bank 4,921지문(교과서 897 + 모의 1,962 + 부교재 2,062), 78만 토큰.

| 밴드 | 단어수 | 교과서 등장률 | 대표 단어 |
|---|---|---|---|
| A1 | 1,036 | 99% | people, mind, manage, medical |
| A2 | 1,036 | 98% | built, catch, unusual |
| A3 | 1,036 | 90% | length, reasonable, originate |
| A4 | 1,036 | 79% | medal, occupy, instruct |
| A5 | 1,036 | 65% | alien, bioluminescence, rub |
| A6 | 1,036 | 52% | glucose, intimidate |
| A7 | 1,036 | 41% | descriptive, migratory, stamina |
| A8 | 1,036 | 33% | glutamate, cocoon |
| A9 | 1,029 | 33% | insistence, suburban |

**검증**: 교과서 등장률이 99→33%로 **한 번도 뒤집히지 않고 감소**. 빈도 밴드가 "학교 교과서에 실릴 확률"과 정렬 = 밴드가 실제 난도를 잡고 있다는 독립 증거.

### 실측으로 확인된 것 3가지

1. **학년도로는 어휘 난도가 안 갈린다** — A1의 학년별 정규화 빈도가 중등 3.66 / 고1 3.52 / 고2 3.48 / 고3 3.36으로 거의 같음(오히려 중등이 높음). 고1 모의와 고3 모의는 **같은 난도 어휘**를 쓴다. 학년 차이는 어휘가 아니라 **지문 구조·추론 깊이**에 있음 → 학년은 어휘 사다리의 주축이 아니라 검증축, **독해 난도 계단은 학년으로** 세운다.
2. **고단끝 강 번호는 난도순이 아니다** — 밴드별 고단끝 중앙 강이 28/27/34/42/54/53/62/66/63강. 진도 기반 판단("45강까지 했으니 중급")이 성립하지 않음 → 밴드를 직접 재야 함.
3. **상위 밴드에서 우리 교재 커버율 붕괴** — A1 79% → A7 21% → A9 11%. 고단끝+중단끝로는 상위권 처방 불가 → 어휘끝 수능(1,854)·EBS VOCA 1800·기출의 바이블(6,493)로 매핑 확장 필요.

**미정제**: 고유명사 오염(minji, klein, mumbai 등), A9 하한이 3회(최소빈도 필터) → 진짜 희귀어 미포함.

### 적응형 엔진 (`adaptive.py`) — 완성·검증

- **틀린 단어 = 암기 흡수율 파트 재료** — 경계 레벨 오답이라 자연히 '학생 수준 +1'이 된다

## ★ 리포트 (`report.py` + `report.html` · `/report?id=`)

### 우선순위 단일 산출 — PRISM 결함 ②의 해결

`report.build()` **하나**가 만든 결과를 상세본·요약본·상담 문구가 모두 참조한다.
PRISM은 상세본이 듣기, 요약본이 문법을 1순위로 제시했다(두 곳에서 각각 계산).
**검증: 상세 1순위 = 요약 1순위 = "어휘" 일치 확인.**

순위 산출 = *부족한 정도 × 되돌릴 수 있는 정도*. 어휘는 커버리지 기여가 커서 1.15배 가중,
독해 유형은 (우리 학생 실측 평균 − 이 학생) × (1+평균), 암기 유지력은 60% 미만일 때 진입.

### 예상 점수는 구간으로

`예상 원점수 = 53.68 + 43.09 × (8문항 정답률)` · RMSE **±11점** (재원생 108명분 회귀).
±11점은 수능 영어 1등급 폭이라 **한 점수로 찍지 않고 구간으로** 표시하고,
재원생 분포에서의 위치(백분위)와 함께 보여준다.
★**정직 표시**: "재원생 108명분(중앙 78점)으로 세운 추정, 오차 ±11점" — 표본 밖이면 그것도 알린다.

### ★ 교재 진도 처방을 버렸다

처음엔 "고단끝 O강부터"로 짰는데, 고1·V2가 53강 / V4가 25강으로 **레벨이 오르는데 강 번호가 내려갔다.**
앞서 확인한 *"고단끝 강 번호는 난도순이 아니다"*(밴드별 중앙 28/27/34/42/54/53/62/66/63강)가 그대로 드러난 것.
→ **진도가 아니라 레벨 단어 목록을 처방**한다: `V4 구간 482단어 · 주 165개(표준 숙제 33×5) · 약 3주 ·
하위보카 커스텀 세트로 내보내 누적 테스트`. 교재는 '이 단어들이 실려 있는 곳'으로만 참고 표시.

## ★ 한국어 뜻 채점기 (`ko_grade.py`, 2026-09-06)

원장 지적 — *"오타가 날 수도 있고, '양립가능한'과 '양립할 수 있는'은 같은 뜻인데 어떻게 채점하나.
'창의성'과 '창의력'도 다 비슷한 거잖아."* 실제로 원장 응시 답안이 정확히 그 두 개였다.

**세 층으로 푼다.**
1. **표현 동치** — `~할 수 있는 ↔ ~가능한`, `~로운/~롭다/~롭게`, `~스러운/~스럽다`, `하게 하다 ↔ 시키다`
2. **접미사 절단** — 성/력/도/함/음/한/인/하다/되다/적인… 을 떼어 **어근**만 비교 (창의성 = 창의력 = 창의).
   2글자 미만으로 깎이면 멈춘다(과다 절단 방지)
3. **오타 관용** — 어근을 **자모 단위로 펴서** 편집거리 1이면 오타로 본다 (정활한 = 정확한 · 창의려 = 창의력)
4. **조사 차이** — 한쪽이 다른 쪽의 부분수열이고 길이 차 ≤2면 정답 (`~와 달리` = `~와는 달리`)

그래도 애매하면 `hold` → 조교가 O/X만 찍는다. **자동으로 다 맞히려 들지 않는다** —
`도구/연장`, `긴박감/긴급함` 같은 진짜 동의어는 문자열로 못 가른다.
테스트 20케이스 전부 통과(`py -3 ko_grade.py`).

**철자 채점**도 5자 이상 단어는 한 글자 오타를 인정하고, **학생이 쓴 철자 원문을 저장**한다
(이전엔 O/X만 남아 무엇을 썼는지 볼 수 없었다).

| 상위권 고3 | V6 | 8/8 | 90% | 86~100 | 전 영역 안정 |
| 중위권 고1 | V4 | 4/8 | 40% | 64~86 | 빈칸 추론 |
| 하위권 중3 | V2 | 1/8 | 20% | 48~70 | 어휘 |
| 어휘만 좋은 고2 | V5 | 3/8 | 50% | 59~81 | 요약 |
| 암기력 낮은 고1 | V3 | 6/8 | 30% | 75~97 | 어휘 |
| 찍은 학생 | V1 미달 | 2/8 | 20% | — | **처방 차단** |

### ★ 샘플이 잡아낸 결함 2건

**① '못하는 학생'과 '안 푼 학생'을 구분하지 못했다.**
하위권 중3(1/8)과 어휘만 좋은 고2(3/8)가 찍은 학생과 똑같이 **처방 차단**으로 나왔다.
그런데 응답 시간을 보면 명확하다 — **하위권은 문항당 73~129초, 찍은 학생은 3~7초.**
정답률만으로 판단한 게 잘못이었다. PRISM을 비판한 것과 **반대 방향의 오류**이고,
진짜 하위권에게 "재측정 필요"만 주면 상담을 못 한다.

→ 플래그에 **severity** 도입. `block`은 **참여하지 않은 증거가 있을 때만**:
  - `too_fast`(15초 미만이 절반 이상) = block
  - `chance` + `too_fast` = block
  - `chance` 단독(시간은 정상) = **note** — "이 세트가 학생에게 너무 어렵다, 더 쉬운 세트로 재확인"
  - `gap`(어휘·독해 편차), `mostly_unknown` = note — "단어는 아는데 글이 안 읽히는 유형일 수 있다"
  화면도 2단으로: 막을 때만 빨간 경고, 나머지는 **"상담에서 짚을 것"**.

**② 단어를 절반도 모르는 중3에게 "글의 요지" 1순위를 줬다.**
독해 유형은 문항이 1~3개뿐이라 `0/1` 하나로 순위가 튄다. 어휘는 9문항으로 안정적인데 밀렸다.
→ 독해 유형 점수에 **표본 신뢰도**(`min(1, n/3)`)를 곱하고,
  **V3 이하면 어휘 가중을 2.0으로** 올린다(단어를 모르면 유형 훈련이 안 먹힌다).
  교정 후: 하위권 중3 = **어휘** 1순위, 어휘만 좋은 고2 = 요약 1순위, 암기력 낮은 고1 = 어휘 → 암기 유지력.

## ★ 문법 진단 — 교재 순서 12단원 · 확신도 설계 (2026-09-06)

### ★★ 확신도 — 원장 설계

*"애들은 개념을 정확히 몰라도 문제를 풀면 자기가 안다고 생각한다."*
→ 문항을 풀고 **바로 확신도**를 받는다(확실해요 / 애매해요 / 모르겠어요).
정답 × 확신을 교차하면 다섯이 갈린다:

| 판정 | 조건 | 처방 |
|---|---|---|
| 안다 | 정답 + 확실 | 넘어감 (핵심 단원만 개념 1문항 확인) |
| 감으로 맞힘 | 정답 + **애매** | 개념 정리 — 맞히긴 하는데 근거가 없다 |
| 흔들림 | 오답 + 애매 | 개념 정리 — 배웠는데 굳지 않았다 |
| ★**오개념** | 오답 + **확실** | 개념 교정 — 잘못 굳은 것부터 |
| 공백 | 모르겠어요 | 처음부터 — 안 배웠을 가능성 |

**'오개념'이 이 설계의 수확이다** — 틀렸는데 맞다고 확신하는 것. 확신을 안 물으면
'흔들림'과 섞여 안 보이고, 그냥 모르는 것보다 교정이 훨씬 어렵다.
2층 진입 순서도 **오개념 → 공백 → 감으로 맞힘 → 흔들림**.

2. **요약 = 제외.** 요약문 자체가 뱅크에 없어 복원 불가 → 변별도 0.549로 최고였지만 뺀다.
   **제목**(0.404)으로 대체.
3. ★**적대검증을 빌더 상시 게이트로.** `balmun_ok()` — 발문이 요구하는 요소

4. **서버가 복원된 지문을 쓰도록 변경** — 이전엔 passage_bank 원문을 직접 읽고 있었다.

조립 16문항 **적대검증 전부 통과**, 학생에게 전송되는 지문에 빈칸이 실제로 들어가는 것까지 확인.

  1. 많이 삼킴(800~1,200자) — 다음 지문 전문. 길이로 보인다.
  2. **조금 삼킴(수십 자)** — 머리말 `고3영어영역3`·각주 `* saline: 식염수`·쪽번호 `aids668`.
     **길이로는 안 보인다.** 길이 이상치만 잡으면 이걸 통째로 놓친다.
  3. 글자 단위 폭발 — 문자열이 리스트에 담겨 한 글자가 한 선지가 됨(선지 203개).
→ **1단은 모든 선지의 꼬리를 정리**(길이 무관), 2단은 폭주분을 마커에서 절단.
  마커로 안 끝나면 **나머지 선지 4개의 길이가 정답을 알려준다**(선지는 형태가 서로 비슷하다).

### 자른 자리는 독립 근거로 검증한다

길이만으로 자르면 근거가 하나뿐이다. **잘라낸 꼬리의 첫머리가 뱅크 안 다른 지문의
시작과 맞는지** 확인했다 — 맞으면 자른 자리가 곧 문항 경계다(46건 확인).
나머지는 꼬리가 지문이 아니라 페이지 장식이라 색인에 없는 게 당연한 경우.
길이 추정에 기댄 4건은 **다른 교재(기출의 바이블)에 같은 지문이 실려** 교차 확인됐다.

### ★제목(Q24)에 주제(Q23)의 선지가 들어가 있었다

`25-06 고2 Q24`는 발문이 '제목', 선지는 전부 돈·보상인데 지문은 손잡이 발달이었다.
**선지 오염보다 나쁘다** — 학생이 문제와 무관한 글을 읽는다.

찾는 법은 **선지 묶음 중복**이었다. 서로 다른 문항이 글자 하나까지 같은 선지를 가질 수
없으니 중복 자체가 증거다(판단 불필요). 정확히 4쌍, 넷 다 Q23(주제)↔Q24(제목).
어느 쪽이 틀렸는지는 **형식이 갈랐다** — 주제는 소문자 명사구, 제목은 Title Case.
`corrected/`에서 지문·선지·정답을 되살렸다. ★고3 모평은 파일명이 학년도라 1년 어긋나므로
`_corrected_alias.json`으로 맞추고 **Q20~30 지문 대조로 번호가 안 밀렸음을 먼저 확인**한 뒤 덮어썼다.

### 어긋남 탐지는 정답 선지 하나로 보면 안 된다

정답만 보면 **함의·제목처럼 일부러 바꿔 말하는 유형이 멀쩡한데도 걸린다**(17건 오탐).
**다섯 선지 전부**를 보고 최대 겹침을 쓴다 — 오답 선지는 지문 단어로 만들기 때문에
지문이 딴 글이면 다섯 개 모두 안 겹친다. 431문항 → 6건으로 좁혀 눈으로 확인, 진짜는 1건.

## 홍보 PDF — 실제 응시 화면으로 만든 학부모 자료 (2026-09-23)

원장 요청: "레벨테스트 우리 학원에서는 이렇게 한다? 홍보성으로 pdf자료 하나 만들어줄 수 있어?
실제 레벨테스트 응시 화면같은거 찍어서!"

**산출물**: `docs/level-test/에이닷_레벨테스트_안내.pdf` (A4 11쪽)

| 쪽 | 내용 |
|---|---|
| 1 | 표지 — "우리 아이, 지금 어디쯤인가요?" + 상담 흐름 3단계 |
| 2 | 점수만 보는 시험과 무엇이 다른가 (4가지) |
| 3~9 | **실제 응시 화면** 7단계 + 각 화면에서 읽어내는 것 |
| 10 | 결과지 — 먼저 잡을 것의 순서 |
| 11 | 재측정 판정 화면 — 못 믿을 응답은 거른다 |

**화면은 전부 진짜다.** 시연 계정으로 처음부터 끝까지 실제 응시하며 각 단계를 떴다.

### 어떻게 찍었나 (다시 만들 때)

응시 화면은 **로그인 토큰을 자바스크립트 변수로만** 들고 있어(`student.html:361`)
새 창으로 열면 늘 로그인 화면으로 돌아간다. 헤드리스로 한 방에 못 찍는다.
→ **응시 중인 화면의 HTML을 그대로 떠서 파일로 남긴 뒤 크롬으로 찍는다.**

1. `_promo_capture.py` — :8795 수집 서버. 브라우저가 직접 저장한다
   (화면 HTML을 대화로 실어 나르면 한 장에 수천 토큰)
2. 브라우저에서 단계마다 `fetch('http://localhost:8795/save?name=...')`.
   ★`<script>`를 빼고 저장해야 파일을 열었을 때 화면이 초기화되지 않는다
3. `_promo_shoot.py` — 크롬 `--headless --screenshot`, `--force-device-scale-factor=2`(인쇄용).
   `trim()`이 **바닥 막대는 남기고 그 위 빈 띠만** 들어낸다
4. `_promo_pdf.py` — HTML 조판 → 크롬 `--print-to-pdf`
   (Word COM은 자동화에서 멈추고, reportlab은 한글 폰트를 따로 심어야 한다)

### 설계에서 정한 것

- **대외물이라 에이닷 브랜드**(네이비 #011337 · 오렌지 #F07D00) + 실로고, 이모지 없음.
  화면 속 갈색은 학생용 앱 색(HAWE 테라코타)이라 그대로 뒀다.
  ⚠️**한 자료에 두 색이 같이 보인다** — 학생 화면도 에이닷 색으로 맞출지는 미결.
- 이름은 전부 **"학생 A"** 로 바꿔 실명이 안 나가게 했다.
- **마지막 쪽(재측정 판정)을 일부러 넣었다.** 자동 응답을 시스템이
  "8문항을 15초 미만에 응답 — 이 결과로 처방을 내지 않습니다"로 걸러냈다.
  홍보물에 재측정 화면을 넣는 건 역설적이지만, **못 믿을 결과는 결과로 쓰지 않는다**가
  다른 학원과 가장 크게 갈리는 지점이라 판단했다. 뺄지는 원장 판단.
