# 분석지·채점 화면이 조용히 비거나 끊기는 사고 모음 (2026-09)

## Summary

파일 검사는 다 통과했는데 **화면에서만** 드러난 사고 8건. 공통 교훈: 데이터에 글이 들어 있는지 확인하는 것으로는 부족하다 — **화면을 열어 문항 수를 세어 본다.**

## Details

| # | 증상 | 원인 | 조치 |
|---|---|---|---|
| 1 | 분석지 전체 빈 화면 | 화면 코드에 닫는 따옴표 누락(9/19 추가분, 9/29 발견) | 고친 뒤 `node --check`로 스크립트 블록 문법 검사를 필수로 |
| 2 | 문항 목록이 10번에서 끊김(감일고1·동신여고2) | 해설의 '번역'을 문자열로 넣었는데 화면은 배열로 가정(`.map`) → 그 문항에서 예외, 뒤 문항 전부 미표시 | 번역은 배열·문자열 둘 다 허용 + `qMidSafe`(한 문항이 오류 나도 나머지는 그림) |
| 3 | 1~4번이 '지문 공유 세트'로 묶임 | note의 `[1~4] 최소성취…` 표지를 세트 참조로 해석 | note에 `[N~M]` 표지를 쓰지 않는다. 발문의 `[14, 논술형 1]`도 QA '참조토큰노출'에 걸린다 |
| 4 | 위례 관제에서 목록 0개 | 화면이 지점을 `adot_branch` 쿠키(없으면 일곡점)로 거름 — 관제엔 그 쿠키가 없음 | 관제용 파일은 지점을 고정(`_build_kwanje_analysis.py`) |
| 5 | 서술형 채점 화면에 '답안을 쓰지 않음' | 대리 입력 때 답안을 통짜 이름(`서술형 1`)으로 저장, 화면은 소문항(`서술형 1-1`)으로 찾음 | 소문항 이름으로 저장 + 화면이 통짜 답안을 쪼개 읽음 |
| 6 | 2학기 분석지에서 오답률 버튼이 1학기 기록을 엶 | `/api/wrongrate`가 학교·학년의 첫 시험(기말)을 잡음 | 분석지 제목을 넘겨 학기·중간/기말·실제 시험 우선으로 고름(`_pick_naesin_exam`) |
| 7 | 오답률 창에서 2개 고르기 문항이 '무응답' | 조합 기호(ⓓ=③⑤)를 ①~⑤만 세는 집계가 버림 | 조합을 풀어 집계·표시 |
| 8 | "Output blocked by content filtering policy"로 작업 중단 | 모의고사 긴 지문 17개를 한 번에 통째로 받아 적음 | 뱅크 원문을 id로 끌어다 쓰고 바뀐 곳만 지정. 뱅크에 없는 글만 짧게 적는다 |

추가로 확인된 것:

- 뱅크 재빌드가 10분 넘게 안 끝남 → 통계 줄에서 집합을 매번 다시 만들던 것(2,460만 회). 루프 밖으로 빼서 수 초.
- 분석 임시 주소(trycloudflare)는 며칠 지나면 오류 루프에 빠지며 주소가 사라진다(프로세스는 살아 있음). `_tunnel_run.ps1` 재실행으로 복구, `_tunnel_watch.ps1`이 5분마다 감시(재부팅 시 자동 실행은 미등록).
- GPT가 만든 결과지는 쪽을 넘쳐 빈 쪽이 생긴다 → 인쇄 보정 CSS를 항상 덧댄다.
- 출처 단정 주의: 뱅크·웹검색 0건이어도 '자작'이 아닐 수 있다(교과서 코너 예문이었음). 같은 지문이 여러 교재에 실리면 뱅크 순서로 엉뚱한 교재가 잡힌다 → `source_prefer/avoid`.

## 재발 방지 규칙

1. 화면 코드를 고치면 `node --check` + 브라우저에서 **문항 카드 수 = 문항 수** 확인.
2. 새 시험은 분석지 파일만 보지 말고 화면에서 끝 문항까지 열리는지 본다.
3. 관제·지점 파일은 비로그인 상태의 기본값(쿠키·지점)에 기대지 않는다.
4. 기록을 대신 넣을 때는 화면이 읽는 키 이름(소문항·조합 기호)을 먼저 확인한다.
