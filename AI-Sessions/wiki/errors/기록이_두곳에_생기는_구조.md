# 같은 성격의 기록을 두 서버가 각자 저장하면, 화면은 반쪽만 본다

## 증상
송유나 조교가 아이패드로 **15:03 출근**을 찍었는데 조교 보드에는 아무것도 안 보였다. 기록 자체는 정상 저장돼 있었다.

## 원인
근태 기록이 **두 곳**에 생긴다.
- 아이패드 키오스크 → `/opt/adot-kiosk/_staff_att.json`
- 예비 웹 화면 → `/opt/adot-dash/_staff_att.json`

보드는 관제 서버 파일만 읽었다.

## 조치
`_staff_att_all()` — 자기 파일 + 키오스크 API(`/api/kiosk/staff_att`)를 합쳐서 본다. 같은 사람·같은 날은 **더 완전한 기록**(퇴근까지 있는 쪽)을 채택.

## 교훈
입력 경로를 여러 개 두면 **읽는 쪽에서 반드시 합쳐야** 한다. 새 입력 경로를 추가할 때는 "이 기록을 읽는 화면이 이 파일도 보고 있나"를 먼저 확인한다. 같은 함정: 원문뱅크·문제뱅크가 흩어질 때와 동일한 구조.
