# 하비 인강 — TLR0(The Logical Reading 0) 교재 전용

## Summary

- 본사 교재 **The Logical Reading 0**를 그대로 미러한 교재 전용 인강. 기존 모의고사 4트랙 강의와 다른 별도 라인.
- UNIT 01 완성(2026-09-20 기준 **83세그 · 약 38분**, 여자 목소리 Gemini Callirrhoe).
- 2026-09-17~20 원장이 직접 보면서 **수업 설계를 여덟 번 뒤집었고**, 그 결과가 지금의 흐름이다: 고르기 대신 직접 쓰기 → 즉시 채점 → 문제 먼저 풀고 근거 찾기.
- ★**공개 배포 금지**(2026-09-18 원장 결정) — 허브(Netlify /habi/)는 화면 단계 로그인이라 음성·그림 주소를 알면 로그인 없이 받힌다. 본사 교재 강의는 **학원 내부(원장 PC 로컬 서버)** 에서만 연다.

## Context

기존 인강 엔진(대본→TTS→장면 조립→페이지)은 그대로 쓰되, **교재 7탭 구조를 화면으로 옮기는** 별도 파이프라인을 만들었다. 원장이 실제로 강의를 처음부터 보면서 준 피드백을 그때그때 반영했기 때문에, 아래 결정들은 "왜 이렇게 되어 있는가"의 근거다.

## Details

**파이프라인 3단** — `tlr0_plan.py`(교안 JSON → 세그 뼈대·화면·정답을 코드가 결정) → `_tlr0/script_uNN.json`(대본, llm 자리만 채움) → `tlr0_assemble.py`(게이트 → TTS → 페이지). 설계 정본은 `_tlr0/*.json`(vocab·bg·passage·nstage·summary·check). ★**설계 JSON을 고치면 `py tlr0_plan.py N`을 반드시 다시 돌려야 한다**(조립기는 plan 파일을 읽는다).

**원장이 바꾼 수업 설계(2026-09-17~20, 시간순)**

| 지시 | 반영 |
|---|---|
| "고르는 거 말고 전부 직접 쓰기, 다 맞으면 바로 넘어가고 틀린 것만 설명" | 떠올리기·어휘 CHECK·N단 빈칸을 직접 쓰기+한 번에 제출로 |
| "해설이 길어 루즈하다. 본문에서 해석·내용·N단을 한 번에" | 본문 탭에 N단 정리를 합치고, 정리·내용파악은 확인용 문제만 |
| "이 책은 흐름대로만" | 안 들은 부분 건너뛰기 금지 + →/← 5초 · 스페이스 재생/정지 |
| "다음으로 안 눌러도 칭찬하고 바로 넘어가게" | 선택형 **62문항 전부** 즉시 채점·자동 넘김(맞으면 1.2~2.8초, 틀리면 해설 음성 뒤) |
| "노트를 밑에 붙이지 말고 오른쪽 여백에" → 필기 사진 제시 | 본문 화면을 **왼쪽 교재 · 오른쪽 NOTE 칸** 2단 격자로, N단 정리를 책처럼 세로로 필기 |
| "보기가 순서대로 배열되어 있는데?" | ★설계 JSON의 단어 칩이 **정답 순서 그대로**여서 읽지 않고 끼워도 만점이었다 → 빌드 때 결정적으로 섞음. 방식도 고르기로 전환 |
| "TEST는 나랑 구두로" | TEST 탭 4화면 삭제, 마무리 대사를 "풀지도 쓰지도 말고 눈으로 보며 입으로 설명" 으로 |
| "전체 듣기 굳이 해야 될까" | 본문 전체 듣기(55.6초) 삭제 — 문장별 해석과 따라 읽기에서 같은 문장을 세 번 들었다 |
| "따라 읽기 말고 따라 해석하기" | 문장 읽어 주고 멈춤 → 학생이 해석 → 하비 해석으로 맞추기(시험 때 구두 해석을 시키므로) |
| "근거 문장을 애들이 직접 찾게" | True/False·내용파악 3번을 **문제 먼저 풀고 → 선지마다 책에서 근거 클릭**으로. 맞으면 통과, 틀리면 해설 뒤 자동 진행 |
| "it이 가리키는 것도 해설" | 책 위에 곡선 화살표로 it → 받은 말 연결(원장 필기 그대로) |

**본문 탭 최종 흐름** — 단어 워밍업 → 제목 → 끊어 읽기란? → 문장 해석 → **풀어보기**(칸에 적기 전 25~32초, 앞 탭 이야기인 깨진 화분·시험 전날 친구 부탁·말랄라를 되불러 씀) → N단 칸 적기 → … → 따라 해석하기.

**화면 장치** — 플레이어 껍데기(`_player_shell.py`: 진행 막대·강의목록·INDEX·북마크·단축키·사전·Q&A, 본사 콜러스 플레이어 구성만 참고) · 학습 잠금(`learn_lock`, 검수는 주소 끝 `#unlock`) · 밝은 '책 느낌' 테마(`_lecture_theme.py`의 `tlr0_book`, 교안 PDF에서 뽑은 교재 색).

**음성** — Cloud Text-to-Speech의 Gemini-TTS(서비스 계정 `_gcloud_sa.json`). AI Studio 경로는 하루 100건 제한이라 강의 1편을 못 굽는다. **받아쓰기 검사**(`gen/tts_asr.py`)가 녹음마다 대본과 대조해 헛말·빠짐을 잡고 최대 4회 재녹음한다.
