# 정국쌤(조정국T) 인수인계 — 2026-10

## Summary

조정국T가 **2026-10-10(토)까지** 근무하고 퇴사한다. 담당 23명을 원장이 전부 이어받는다. 인계는 **토요일 2회**(10/3·10/10)로 나누고, 학생별 인수인계 기록은 관제 화면에서 자동 저장 방식으로 받는다. 학부모에게는 정국쌤이 직접 전화한다.

## Context

- 사유 = 개인 사정. 학부모에게 말하는 문장은 **"개인적인 사유로 그만두게 되어 이번 내신까지만 함께하게 됐습니다"** 한 줄로 고정(원장 확정 9/18).
- 인계 후 원장이 우리반 47 + 정국쌤반 23 = **약 70명**을 혼자 맡는다 → [[원장1인_시간표_2026-10]]
- 원장 본인도 12/31 퇴임 예정이라, 정국쌤반 23명은 **두 달 사이 담당이 두 번 바뀐다** → [[원장_퇴임_2026-12]]

## Details

### 1. 인계 일정 (학생 23명)

| 차수 | 날짜 | 인원 | 대상 |
|---|---|---|---|
| 1차 | 10/3(토) | 16명 | 10/2까지 시험이 끝나는 12명 + 고려중 3·살레시오고 1 |
| 2차 | 10/10(토) · **정국쌤 마지막 근무** | 7명 | 일동중·문정여고·숭일고·동명고 |

- 인계일에 수업이 있는 학생(조민성·염시윤 10/3, 김지민 10/10)은 **그날 수업을 두 사람이 같이** 하며 넘긴다.
- ★**고려중 3명(김동하·강다원·최지후)·살레시오고 1명(김민욱)** 은 시험이 10/14~15라 인계가 시험 앞에 걸린다 → 10/3에 인계하되 **10/10까지는 정국쌤이 시험 대비를 계속하고 원장이 동석**, 그 뒤부터 원장 단독.
- 원장 단독 첫 수업 = 10/5~10/17에 분산. 일정표 원본 = `…\에이닷 필요자료\정국쌤_인수인계\정국쌤_인수인계_일정표.docx`

### 2. 관제 인수인계 페이지 (hawecontrol.com/dashboard/handover.html)

- 관제 → 더보기 → 학습 관리 → **인수인계**. 원장·선생님만 열리고 조교는 서버에서 차단.
- 칸 구성은 본사 운영 시트 '인수인계' 탭과 동일(이동횟수·재원기간·예상T·진도·특이사항·학부모 특이사항·비고). **맨 위에 지소윤 예시**(예전 시트 실제 작성분)를 고칠 수 없게 띄워 기준을 보여 준다.
- **저장 버튼이 없다.** 입력을 멈추면 1초 안에 칸 단위로 저장되고, 끊겨도 기기에 보관했다가 재전송한다. 칸 단위 병합이라 두 사람이 같이 써도 서로 덮어쓰지 않는다. 바뀌기 전 값은 `_handover_log.jsonl`에 남는다.
- 데이터 = VPS `/opt/adot-dash/_handover.json`
- 인수자(예상T) 칸은 23명 전원 **"원장님"** 으로 채워 둠.

### 3. 인수인계 달력 (같은 페이지 상단)

- 9/28~10/18 **3주**, 날짜마다 **왼쪽 원장 / 오른쪽 정국쌤** 시간표를 나란히 놓고 그 위에 인계 약속을 얹는다.
- 학생 수업을 누르고 → 시작 시간을 누르면 **정국쌤 30분 → 원장 30분** 짝 일정이 한 번에 잡힌다(시간 20·40·60분 조정 가능). 수업과 겹치면 빨갛게 경고.
- 그 주에 내신이 끝나는 학생은 분홍색. 시간표 출처 = 키오스크 `_sched.json` 사본(호스트 크론 10분마다 복사).
