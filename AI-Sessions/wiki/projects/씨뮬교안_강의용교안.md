### 축적된 핵심 기법·함정 (재사용 가치)
- **단어 배분 = 단조 정렬 DP 필수.** 순차 지문 걷기는 한 지문에서 발이 걸리면 뒤가 전부 무너짐(씨뮬 3회 80/1423·첫단추 1회 108/368 사고). 전권 지문을 후보로 DP(배정/버림/지문이동) — 경계 지문 몇 개로는 뒷회차 단어를 못 흡수해 마지막 지문에 쏠림(제3회 Q41 128개 사고).
- **페이지나눔**: `add_page_break()`·문단 내 w:br 모두 앞 내용이 쪽을 채우면 빈 쪽 생성 → **다음 문단 `page_break_before=True`(2pt 문단)**이 유일하게 안전.
- **폰트**: KoPubWorld돋움은 영문명(`KoPubWorldDotum_Pro *`)으로 지정 + `AddFontResourceW`+`WM_FONTCHANGE` 세션 등록. LibreOffice는 사용자 폰트 인식 불가 → Word COM 전용.
- **Word COM 일괄 PDF 변환 시 일부 파일 조용히 누락**될 수 있음(4회 학생용·3회 선생님용 재현) → 변환 후 `_pdf` 존재 확인, 없으면 단건 재변환.
- **삽화 프롬프트 3원칙**(원장 피드백): 키워드 지배(글자 없이 2초 안에 주제 유추)·미니멀(장면≤2·소품≤5)·대조 지문은 양쪽 상태 모두. 부적절하면 flow JSON `illust` 필드로 수동 구도.
- **특별부록**: 단어장 범위 밖 → Word List를 content `words` 필드에 지문 선별 어휘(~10개) 수동 수록. 뱅크 lesson='특별부록 N회'.
