### 5. 빠른채점 (앱 v68 → v76)

- 자동 저장(v70): 채점 즉시 기록 → 마킹·서술 자가채점·메모가 바뀌면 같은 줄 갱신 → 제출하기는 몇 번 눌러도 같은 줄 갱신. 원장: "애들이 채점만 하고 제출 안 누르고 끈다".
- 선생님 서술형 채점 화면: 분석 사이트(8765) 오답률 창 → 학생별 [서술형 채점] — 학생 답안·자가채점·모범답안 나란히, 만점/0점 버튼. 바로가기 `http://localhost:8765/#seosul=학교|학년|제목 일부`.
- 2개 고르기 문항은 조합 기호 1자(③⑤=ⓓ, ④⑤=ⓔ)로 저장. 오답률 창이 조합을 풀어서 보여 주게 고침.

### 6. 학부모 결과 리포트 PDF — GPT 구독 연동

- `C:\모의고사자동화\_gpt_report.py "<빠른채점 시험명>" <학생아이디>` → 채점기록+해설 JSON → **Codex CLI**(`codex exec`, ChatGPT Pro 로그인, 구독 한도) → HTML → Chrome headless PDF → `_reports\`.

### 8. 분석지 화면 개편 (원장 9/30)

- 목록을 **학기별 묶음**(최근 학기 위).
- 문항 **좌우 배치**: 왼쪽 원지문·원문 대비, 오른쪽 기출 문제(발문·지문·선지·정답·해설). 폭 1360px, 좁으면 위아래.
- **대화문**은 화자마다 줄바꿈·내어쓰기, (A)(B)(C)는 제자리 빈칸. 화자 표지 3개 이상이면 자동 적용.
- **<보기> 상자·제시 문장**을 그대로 표시(OCR note → `보기`).
