## 2. VPS 이전 (3단계) — 주소 `https://hawecontrol.com`

원장 결정: "내 컴퓨터 켜짐/꺼짐과 무관하게" → **관제 전체 이전** + HTTPS부터 제대로.

| 단계 | 내용 |
|---|---|
| 1 | 관제 본체·정본 데이터 → `/opt/adot-dash/`. 컨테이너 `adot-dash`(python:3.12-slim, 8096) + traefik 라벨로 HTTPS |
| 2 | 성적·숙제·단어·본사CRM(`exam_server`) → `/opt/adot-grade/`(8097, **도커 게이트웨이에만 바인딩**해 외부 노출 0) |
| 3 | **빠른채점** → 학생 주소 `hawecontrol.com/grade`(로그인 없음). 듣기 클립 43MB 업로드 |

- **★traefik은 docker provider만 쓴다** → 호스트 서비스로 라우팅 못 함. 그래서 관제를 컨테이너로 띄웠다.
- **★HTTPS 때문에 필요했던 것**: https 페이지에서 `http://…:8095`를 직접 부르면 브라우저가 막는다(mixed content) → 서버가 `/api/kiosk/*`·`/api/nudge/*`·성적 API를 **같은 출처로 중계**(토큰은 서버에만). 프론트는 서버가 심는 `window.__DASH=1`로 `ON_DASH` 분기.
- **★리눅스 이식 3군데**: `exam_server.BASE_DIR`·`sheets_client.BASE_DIR`를 `os.name!='nt'`면 파일 폴더로(윈도우는 기존 경로 유지 → 로컬 빠른채점 무영향).
- **★빠뜨리기 쉬운 파일 3개**(없으면 조용히 빈 결과): `_grade_sheet_id.txt`(없으면 모의고사DB로 폴백해 성적 0명), `_grade_exam_meta.json`, **`_crm_passwd.txt`**(`_crm_secrets.json`의 passwd는 비어 있음 → 없으면 본사 로그인이 "비밀번호를 입력해 주세요"로 실패).
- 컷오버: 정본 재복사(md5 5개 일치) → 로컬 5173은 `_moved_to_vps.txt`가 있으면 `/dashboard`·`/studyroom`·`/naesin`을 열지 않고 **이사 안내**(저장 API는 410). **아이패드 키오스크(`/kiosk/`)는 게이트·잠금 밖**(기기는 로그인할 수 없다).
- 도메인: 원장이 Hostinger에서 `hawecontrol.com` 구매(1년, **만료 2027-08-10 → 자동갱신 확인 필요**). A `@`·기본 CNAME `www`, **Hostinger 파킹 A(2.57.91.91) 삭제 필수**. LE 인증서 자동갱신. 옛 `72-62-252-20.sslip.io`도 함께 열어둠.
- 루트(`/`)는 무조건 관제 — 예전엔 학생관리 폴더의 옛 `index.html`(단어 테스트 기록 링크)이 떠서 빈 화면처럼 보였다.

## 4. 관제 기능 수정 (이 세션)

- **자습실을 별도 페이지로 분리** — 예전엔 iframe으로 겹쳐 띄워 3초·30초 주기 `render()`가 원래 뷰를 되살려 아래에 같이 보였다. 이제 `/studyroom/` 이동 + 제목 옆 `← 관제로`(왔던 화면으로 복귀, 학원 PC에서만 표시).
- **슬롯 충돌 경고를 주 단위로** — `activeMove`(다음 주 지정분 미리 반영)를 써서 **다음 주 보충이 이번 주 자리 충돌로 잡혔다**. `slotOccupants(day,time,exclude,weekKey)`로 그 주만 보고, 이월·재택·휴면 주는 자리 빔으로 처리.
- **예약 시간표 변경** — 방학 뒤 새 시간표를 미리 등록. `profiles[이름].pending={from,day,time,self}`. UI는 **적용 시작일 날짜 한 칸**(이번주/다음주 버튼은 원장 지시로 제거). 시작일>오늘이면 예약, 오늘로 되돌리면 취소. 발효는 `promotePending()`(부팅 시). 시간표는 보고 있는 주 기준(`effDayW(r,TT_WEEK)`)이라 다음 주 표에서 미리 확인 가능.
- **★설정칸이 접히는 버그** — `renderClass()`가 매번 접이칸을 초기화해 요일칩·날짜를 누르면 칸이 닫혔다 → `renderClass(name, keepFold)`.
- **★동명이인 프로필 공유 사고** — `profiles.json`이 이름 키라서 두 김민성이 한 프로필을 공유했다(한쪽 시간표를 바꾸면 다른 쪽도 바뀜). **이름이 겹치는 학생만** 키를 `이름|loginId`로(`DUPNAMES`·`pkey(r)`·`dispName`·`rosByKey`). 겹치지 않는 학생은 예전 키 그대로라 기존 데이터 보존. **여는 경로도 키를 넘겨야 한다** — 카드·출결행·검색Enter가 이름으로 열어 분리 후에도 첫 학생만 열렸다.
- **★함수명 충돌로 시간표가 통째로 안 뜸** — 새로 만든 `pk()`가 시간표 코드의 지역 변수 `pk`에 가려져 `pk is not a function`. `pkey()`로 개명. **문법 검사는 통과하는 종류의 오류 → 화면을 직접 열어봐야 잡힌다.**
- **모의고사 meta 미등록 자동 분류** — `_grade_exam_meta.json`에 없는 시험은 학생창에서 통째로 빠졌다(서킷 12~15회 40건). 이름으로 판정: `^YY-MM 고[123]$`=전국 모의 / 중간·기말고사=내신 / 나머지=사설. **★9월 학평도 미등록이었으므로 "공식 아니면 전부 사설"로 하면 안 된다.**
- 단어시험 **채점 수정 경로 누락**(`/api/wordtest/regrade`)으로 "not found" → `GRADE_PATHS`를 `/api/wordtest` 접두사로 확장. 단어 인증 패널은 기록 도착 전 "확인 중…"으로 표시(인증한 학생이 미완으로 보이던 문제).
